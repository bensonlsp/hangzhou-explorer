# 杭行 · Hangzhou Explorer

以簡化3D航拍視角探索杭州與江南：西湖、西溪濕地、大運河杭州段、錢塘江、浙江省博物館之江館區、烏鎮。

## 使用

按「湖山、水岸、文化、周邊」選擇景點，自由飛行或環繞觀看。沒有固定日程或遊覽路線。

手機和平板使用拖曳、搖桿、升降按鈕與雙指縮放。電腦使用 WASD 移動、RF 升降、方向鍵轉向、滑鼠拖曳及滾輪。Esc 停止動態。

## 發布

純靜態 ES modules，使用本地 Three.js，沒有編譯步驟或 API key。GitHub Pages 可選 main 分支的根目錄；`.nojekyll` 已包含。本機可執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。不能直接用 file URL 載入 modules。
